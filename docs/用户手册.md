# MinBrowser 用户手册

MinBrowser 是一个注重隐私的浏览器：**不收集任何数据**，你的浏览记录、收藏夹、密码和打开的标签页都用你的**主密码加密**，保存在你自己选的文件夹里。

当前版本见设置页或新标签页底部。本手册适用于 v1.2。

## 1. 安装与启动

### 用安装包（推荐）

- **macOS**：打开 `MinBrowser-<版本>-arm64.dmg`（Apple 芯片）或 `x64.dmg`（Intel），把 MinBrowser 拖进“应用程序”。
  第一次打开时 macOS 会提示“无法验证开发者”：在“访达”里**右键点击 MinBrowser →“打开”→ 再点“打开”**。
- **Linux**：`sudo apt install ./minbrowser_<版本>_amd64.deb`；或者给 AppImage 加执行权限后直接运行。

安装包可以在 GitHub 的 **Actions → Build → Run workflow** 里生成，也可以自己打包（见 `docs/RELEASING.md`）。

### 从源代码运行

```bash
npm install     # 第一次，或更新代码后
npm start
```

Linux 上如果报 `chrome-sandbox` 错误，执行一次：

```bash
sudo chown root:root node_modules/electron/dist/chrome-sandbox
sudo chmod 4755 node_modules/electron/dist/chrome-sandbox
```

想在应用菜单里看到 MinBrowser、任务栏显示它的图标，执行一次 `npm run install-desktop`。

## 2. 第一次使用

1. **选择数据文件夹**：所有数据都会加密存在这里。可以是任何你有写权限的文件夹，以后整个复制就是备份。
2. **设置主密码**：至少 8 个字符，建议用一句只有你知道的话。下面的强度条会提示强弱。
3. **输入确认语句“我明白忘记密码将无法恢复”**，点“创建并开始浏览”。

> ⚠️ **主密码没有任何找回方式。** MinBrowser 不保存主密码，忘记了，所有浏览记录、收藏夹和密码都将永久无法打开。请把它记在安全的地方。

以后每次启动，都要先输入主密码解锁。

**从 Chrome 搬过来**：打开 菜单 ⋯ → 收藏夹 → “导入…”，选择电脑上找到的 Chrome，或者选 Chrome 导出的书签文件。

## 3. 浏览网页

### 地址栏

- 输入网址直接打开；输入其他内容就用 **DuckDuckGo** 搜索。
- 地址栏左边的图标：🔒 表示安全连接（https），🌐 表示未加密的连接。
- 地址栏右边的 ☆：收藏这个网页（见第 5 节）。

### 标签页

- 新建：点标签栏右边的 **+**、按 ⌘/Ctrl+T，或在标签栏空白处双击。
- 关闭：点标签上的 ×、按 ⌘/Ctrl+W，或用鼠标中键点标签。
- **调整顺序：按住标签左右拖动。** 也可以用 Ctrl+Shift+PageUp / PageDown 把当前标签左移或右移。
- 右键点标签：分屏、关闭等操作。

### 工具栏按钮（从左到右，地址栏右边）

| 按钮 | 作用 |
|---|---|
| 🔑 钥匙 | 当前网页有登录框或已保存密码时出现，点它选择账号填入 |
| 🛡 盾牌 | 显示这一页拦截了多少广告和追踪；点一下在这个网站停用拦截 |
| ● 记录中 / ⏸ 已暂停记录 | 点一下暂停或恢复记录浏览历史 |
| ↓ 下载 | 打开下载列表；数字是正在下载的数量 |
| ⋯ 菜单 | 历史记录、收藏夹、密码、下载、设置、立即锁定等 |

## 4. 分屏

大屏幕上可以同时看两个网页（左右或上下）。

**开启分屏：**

- 在标签上**点右键 →“在右侧分屏打开”或“在下方分屏打开”**；或者
- **按住标签往下拖进网页区域**，拖到**右边缘**（左右分屏）或**下边缘**（上下分屏），看到橙色预览后松手。

**分屏时：**

- **当前那一边有橙色边框**。你点哪一边，地址栏、☆、密码填充就跟着哪一边。
- 拖动中间的**分隔条**调整两边大小。
- 点标签栏里的其他标签，会**替换当前那一边**。
- 右键分屏中的标签：切换左右/上下、交换两侧、退出分屏。
- 关掉其中一边，就自动退出分屏。
- 分屏状态在重启或崩溃后会恢复。

## 5. 收藏夹

### 收藏网页

- **点地址栏里的 ☆**：立即收藏到你上次选的文件夹，并弹出小窗口，可以改名称、**选文件夹**、写一句描述。回车保存，Esc 或点别处关闭；点“移除”取消收藏。
- **按住地址栏左边的图标（🔒/🌐），拖到收藏夹栏**：
  - 拖到某个**文件夹**上：收藏进这个文件夹；
  - 拖到**两个收藏之间**：插在那个位置；
  - 拖到空白处：放到最后。
  放下后同样会弹出小窗口，可以再选更深一层的文件夹。
- 网页里的链接也可以直接拖到收藏夹栏上。

### 收藏夹栏

地址栏下面的一排就是收藏夹栏（⌘/Ctrl+Shift+B 显示/隐藏）。点文件夹会弹出菜单列出里面的收藏；按住 ⌘/Ctrl 点或用中键点，在新标签页打开。

### 管理收藏夹（菜单 ⋯ → 收藏夹，或 ⌘/Ctrl+Shift+O）

- **左边**是可折叠的文件夹树，数字是里面有多少个收藏。
- **右边**是当前文件夹的内容，可以切换**列表**或**卡片**视图。
- **拖动整理**：拖到两项之间调整顺序；拖到文件夹上（右边列表、左边树、顶部路径都行）放进去。
- **多选**：⌘/Ctrl 点击逐个选，Shift 点击选一片；底部会出现操作栏，可以批量移动、打开、删除。
- **双击**打开；**Delete** 删除；**Esc** 取消选择；**⌘/Ctrl+A** 全选。
- 点“编辑”可以改名称、网址和**描述**；搜索框会同时搜标题、网址和描述。
- 点“导入…”从 Chrome 或书签文件导入。重复导入不会产生重复项；已有收藏缺的描述会被补上。

## 6. 浏览记录

- 默认**记录中**：每个网页的网址、标题、访问时间、停留多久、从哪个页面过来。网址里的追踪参数（如 `utm_`、`fbclid`）和登录凭证会自动去掉，不会记录。
- **暂停记录**：点工具栏的“记录中”按钮（或 ⌘/Ctrl+Shift+P）。暂停时按钮变成橙色的“已暂停记录”，这段时间不写任何浏览记录。
- **查看**：菜单 ⋯ → 历史记录（⌘Y / Ctrl+H）。按日期分组，可以搜索（支持中文）、删除单条，或删除最近一小时 / 24 小时 / 7 天 / 全部。
- **导出**：历史记录页的“导出 CSV / 导出 JSON”。⚠️ 导出的文件**不加密**，请妥善保管。

## 7. 密码

### 保存

登录网站后，地址栏下方会出现“保存 xxx 的密码？”：

- **保存**：加密保存这个账号；
- **暂不**：这次不保存；
- **此网站永不保存**：以后不再询问（可在密码页面撤销）。

### 自动填充

- 打开登录页时，会**自动填入**这个网站最近用过的账号（只在 https 网站和本机地址上，只填空着的输入框）。
- **分步登录**（先输邮箱、点“下一步”再输密码，例如很多学校、银行网站）：第一页自动填用户名；第二页按你刚才输入的用户名填对应的密码。
- 也可以点 🔑 钥匙按钮，从菜单里选择账号填入，或者“生成强密码并填入”（注册新账号时用）。
- 不想自动填：设置 → 隐私 → 关闭“自动填充密码”。

### 管理（菜单 ⋯ → 密码）

- 显示 / 隐藏、**复制**（30 秒后自动从剪贴板清除）、编辑、删除；
- 手动添加账号，“生成”按钮可以生成强密码；
- 管理“永不保存”的网站列表。

## 8. 隐私保护

这些都是**默认开启**的：

- **不收集任何数据**：没有遥测、没有崩溃上报，不连接任何“统计”服务器。
- **屏蔽第三方 Cookie**：别的网站嵌在页面里的追踪器拿不到你的 Cookie。
- **广告和追踪拦截**（EasyList + EasyPrivacy）：盾牌按钮上的数字是这一页拦掉的请求数。某个网站因为拦截不正常时，点盾牌在这个网站停用。规则每 7 天自动更新，也可以在设置里手动更新。
- **加密 DNS**：你访问哪些网站，不会被网络运营商从 DNS 里看到。
- **隐藏本机网络地址**：网页无法通过 WebRTC 获取你电脑的局域网 IP。
- **权限每次都问**：摄像头、麦克风、定位、通知、屏幕录制等，网站必须先征得你同意；你的选择只记到浏览器关闭为止。锁定期间一律拒绝。
- **搜索用 DuckDuckGo**。

想要更私密：设置 → 隐私 → 开启“**退出时清除 Cookie 和网站数据**”（代价是每次都要重新登录网站）。也可以随时点“立即清除”。

> 说明：网站本身、以及你的网络运营商，仍然能看到你访问了哪些网站（IP 地址），这是任何浏览器都无法避免的。

## 9. 下载

- 文件默认保存到系统的“下载”文件夹。设置 → 下载 里可以**更改位置**，或开启“**每次下载前询问保存位置**”。
- 工具栏 ↓ 按钮打开下载列表：暂停 / 继续 / 取消、打开、在文件夹中显示。
- 下载列表只保存在这次运行期间，**不会写入磁盘**；文件本身当然会保留。

## 10. 锁定与主密码

- **自动锁定**：电脑闲置 15 分钟（可在设置里改为 5 / 30 / 60 分钟或从不）、电脑锁屏或睡眠时，MinBrowser 会自动锁定。
- **立即锁定**：⌘/Ctrl+Shift+L，或 菜单 ⋯ → 立即锁定。离开电脑时建议使用。
- 锁定后网页会隐藏，需要输入主密码才能继续；标签页不会关闭。
- **修改主密码**：设置 → 数据与安全 → 修改主密码。数据不需要重新加密，修改很快。
- **忘记主密码**：没有任何恢复办法，数据无法打开。只能在锁定界面点“使用其他数据文件夹”重新开始。

## 11. 崩溃恢复

- 浏览器关闭、意外崩溃或被强制结束后，下次解锁会**重新打开之前的所有标签页**（包括分屏），停在你最后看的那个。只有当前标签马上加载，其他标签第一次点开时才加载。
- 某个网页单独崩溃时，会显示“这个网页崩溃了”，点刷新即可。
- 不想恢复：设置 → 隐私 → 关闭“启动时恢复上次打开的网页”。

## 12. 设置一览

菜单 ⋯ → 设置（⌘, / Ctrl+,）：

| 分组 | 设置项 |
|---|---|
| 数据与安全 | 数据文件夹位置、自动锁定时间、立即锁定、修改主密码 |
| 隐私 | 自动填充密码、启动时恢复上次的网页、暂停记录浏览历史、退出时清除 Cookie 和网站数据、立即清除 |
| 广告和追踪拦截 | 开关、更新规则、已停用拦截的网站列表 |
| 下载 | 下载位置、每次下载前询问 |
| 外观 | 显示收藏夹栏；深色模式跟随系统 |

## 13. 备份与换电脑

- **备份**：关闭 MinBrowser，把整个数据文件夹复制到 U 盘、NAS 或网盘。里面的文件都是加密的。
- **换电脑 / 恢复备份**：在新电脑上打开 MinBrowser，首次设置时选择这个文件夹（会提示“这个文件夹里已经有 MinBrowser 数据”），点“使用这个文件夹”，用原来的主密码解锁。已经在用的话，在锁定界面点“使用其他数据文件夹”。
- ⚠️ 不要让两台电脑**同时**打开同一个数据文件夹（例如通过网盘实时同步）。

## 14. 更新与版本

- 版本号格式是 **vN.N**：小改动升 0.1，大改版升 1.0。每个版本改了什么见 `CHANGELOG.md`。
- 浏览器的安全依赖 Chromium 内核及时更新，建议**每月**按 `docs/RELEASING.md` 升级一次 Electron。

## 15. 常见问题

**登录 Google 时提示 “This browser or app may not be secure”？**
Google 不允许 Electron 这类嵌入式浏览器登录 Google 账号。Gmail、YouTube 等需要登录的 Google 服务请用系统自带的浏览器（如 Firefox）。

**为什么某个网站没有自动填充密码？**
- 网站是 http（不加密）的：点 🔑 钥匙按钮手动填；
- 打开 菜单 ⋯ → 密码，看看这个网站的记录用户名是不是“（无用户名）”。如果是，正常登录一次，浏览器会自动补上用户名；
- 设置里是否关闭了“自动填充密码”。

**Netflix、Spotify 网页版不能播放？**
这些网站使用 DRM 版权保护，MinBrowser 不支持。

**网页显示不正常？**
先试试点 🛡 盾牌，在这个网站停用拦截。

**任务栏显示的是齿轮图标？**
在源代码目录执行一次 `npm run install-desktop`，必要时注销再登录。

**数据文件夹里都有什么？**
`vault.meta`（被主密码保护的数据密钥）、`*.db.enc` 和 `*.journal`（加密的数据库）、`config.json`（不敏感的设置）、`chromium/`（网站的 Cookie 和数据，只有你的账户能读）。详细的安全说明见 `docs/SECURITY.md`。
